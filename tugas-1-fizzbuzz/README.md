# Tugas 1 — FizzBuzz Project (Python)

Program berbasis **Python** dengan fitur input interaktif yang menampilkan angka dari 1 hingga batas yang ditentukan (default: 100) sesuai aturan FizzBuzz:
- Habis dibagi 3 dan 5: menampilkan **"FizzBuzz"**
- Habis dibagi 3: menampilkan **"Fizz"**
- Habis dibagi 5: menampilkan **"Buzz"**
- Angka lainnya: menampilkan angka itu sendiri

---

## 🚀 Fitur Input Pengguna

Saat program dijalankan, program akan meminta input batas angka:
- Anda dapat memasukkan angka bulat positif berapa pun (misal: `50`, `100`, `15`).
- Jika Anda langsung menekan tombol **Enter** (kosong), program otomatis menggunakan nilai default **100** sesuai instruksi tugas awal.

---

## 💻 Cara Menjalankan

Pastikan **Python** (versi 3.x) sudah terpasang di komputer Anda.

1. Buka terminal pada folder `tugas-1-fizzbuzz`.
2. Jalankan perintah:
   ```bash
   python fizzbuzz.py
   ```
3. Masukkan batas angka yang diinginkan atau tekan **Enter** untuk menjalankan 1 sampai 100.
